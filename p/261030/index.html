前情提要

ERV 项目的目的是解决情绪感知模型的思考与识别结果可能存在不匹配的问题。其通过加入小模型ERV进行打分，通过强化训练机制调整模型，提升其对齐效果。

ERV 部署

已通过 docker 和伟大的ChatGPT 完成了ERV模型自己的“仅推理”部署，但是能不能优化大模型还是未知数。

from transformers import BertTokenizer
from humanomni import model_init, mm_infer
from humanomni.utils import disable_torch_init

# 1. 配置模型
config = {
    "model": {
        "mm_vision_tower": "google/siglip-base-patch16-224",
        "mm_audio_tower": "openai/whisper-large-v3",
        "model_size": "0.5B",
    }
}

# 2. 加载模型
bert_tokenizer = BertTokenizer.from_pretrained("bert-base-uncased")
disable_torch_init()

model, processor, tokenizer = model_init(
    "/workspace/models/ERV-0.5B",
    **config
)
model.eval()

# 3. 处理单个视频
video_path = "/workspace/ERV/test_videos/test.mp4"

video_tensor = processor["video"](video_path)
audio_tensor = processor["audio"](video_path)[0]

# 4. 模型推理
prompt = (
    "As an emotion recognition expert, what is the most obvious "
    "emotion conveyed by the characters throughout this video? "
    "Output the thinking process in <think> </think> "
    "and the final emotion in <answer> </answer> tags."
)

result = mm_infer(
    video_tensor,
    prompt,
    model=model,
    tokenizer=tokenizer,
    modal="video_audio",
    question=prompt,
    bert_tokeni=bert_tokenizer,
    audio=audio_tensor,
    model_size="0.5B",
    do_sample=False,
    max_new_tokens=128,
)

print(result)

GRPO 拾遗

GRPO的损失函数如下：

$$ \max_{\pi_\theta} \mathbb{E}_{o \sim \pi_\theta(x)} \left[ R(o) - \beta \cdot \mathrm{KL} \left( \pi_\theta(o|x) \parallel \pi_{\mathrm{ref}}(o|x) \right) \right] $$

$R(o)$是输出序列（回答）为 $o$ 时的奖励；
其中$\pi_\theta$就是模型前向传播的函数，其所有参数为$\theta$；
$\pi_\theta(o|x)$表示上下文为$x$时，输出序列为 $o$ 的概率；
KL表示参考模型与策略模型的偏差，一致时为0，越大偏差越大。 $\beta$ 是这部分的权重;
所以方括号里的就是奖励减去偏差，表示输出序列 $o$的优化收益。

$\mathbb{E}{o \sim \pi\theta(x)}$ 表示基于上下文 $x$ 给出的全部 $G$ 个输出序列 $o$ ，右边那一堆的期望。而 $max_{\pi_\theta}$ 表示让这个期望最大的参数 $\theta$ 的选择。

所以这个损失函数依旧是关于参数 $\theta$ 的可微函数，符合正常的模型训练逻辑。奖励函数起到的作用就是评价生成结果 $o$ 的好坏，从而让模型向着高优势的结果的方向进行反向传播。
